# INN — Intrinsic Neural Networks

**외부 입력 없이도 스스로 상태를 유지하고 행동하는 에이전트, "공학적 자아"를 만들어 보는 개인 연구 프로젝트**

## 목표

"자아"라는 말을 그대로 쓰면 검증할 수 없기 때문에, 이 프로젝트는 자아를 **측정할 수 있는 성질**로 나누어 하나씩 구현하고
검증하는 것을 목표로 한다.

| 성질 | 공학적 정의 (검증 방향) |
|---|---|
| 능동성 | 외부 입력 없이도 스스로 행동을 시작한다 |
| 항상성 | 내부 변수를 기준 범위로 유지하려는 조절이 행동에 영향을 준다 |
| 연속성 | 재시작 후에도 이전 기억에 근거해 일관되게 행동한다 |
| 자기 모델 | 자기 내부 상태의 다음 변화를 스스로 예측한다 |

"의식"이나 "주관성"을 주장하지 않는다. 위 성질들을 실제로 구현하고, 사전에 정한 기준으로 시험하는 것이 목표다.

## 현재 구성 요소 (2026-11 측정 기준)

| 구성 요소 | 의도 | 지금 코드의 실제 상태 |
|---|---|---|
| 내부 신호 | 로지스틱 사상(r = 3.75)의 혼돈 영역으로 입력 없이도 변하는 신호 | 사상을 실제로 반복하는 신호로 바꿨다(신호의 리아푸노프 지수 +0.36). 같은 분포의 난수, 같은 자기상관의 잡음과 비교했을 때 엔진 내부 상태(의지 변수 I)의 순서 구조가 20개 시행 모두에서 달랐다(순열 엔트로피 0.86 대 0.94~0.99). 다만 먼저 말을 거는 타이밍은 이 신호가 정하지 않는다(아래 "지속 기억과 능동적 생각 루프" 행) |
| 자기 모델 | 자기 내부 상태의 다음 변화를 스스로 예측 | 엔진 안의 온라인 예측기가 다섯 상태 변수의 다음 변화를 경험으로만 배워 예측한다(엔진의 식·함수를 쓰지 않는지 소스 검사로 확인). 오차가 "변화 없음" 예측보다 30% 낮고(비율 0.70), 같은 학습기에 겉으로 보이는 정보만 준 관찰자(0.81)보다 20개 시행 모두에서 낫다. 이득은 대부분 내부 혼돈 신호를 알기 때문이다. 엔진 상수를 중간에 바꿔도 다시 맞춘다. 긴 교란 뒤 재학습(M3b)도 통과했다. 100분 동안 자극을 바꾸면 오차가 올랐다가 학습으로 다시 줄고, 교란이 끝나면 평소 수준으로 돌아온다. 기준을 정할 때 본 시행 20개와 따로 남겨 둔 시행 20개 모두에서 20개씩 통과했고, 같은 교란에서 학습을 멈춘 예측기는 0개 통과했다. 짧은 교란(50틱)으로 잰 처음 시험(M3)은 판별력이 부족해 기준 미달(20개 중 15개, 기준 16개) 기록을 그대로 둔다. 예측을 행동에는 쓰지 않는다 |
| 스파이킹 신경망 (LIF 뉴런) | 입력을 시간에 따른 스파이크로 처리 | 모듈은 있으나 실제 동작 경로에 연결되어 있지 않다 |
| 부하 기반 자기 조절 | 내부 부하가 기준을 넘으면 처리를 줄이는 상태로 전환 | 에너지(G)가 설정점 0.6 아래로 내려가면 생각을 멈추고 쉰다. 깨어 있는 동안 쉬는 시간과 꺼져 있던 시간을 같은 식으로 회복한다(시간당 0.1, 최대 7일). 24시간 동안 기준 범위 안에 있던 시간이 100%였고, 조절만 끈 같은 엔진은 5.6%였다. 설정점을 0.5·0.6·0.7로 바꾸면 그 값을 따라간다 |
| 지속 기억과 능동적 생각 루프 | 재시작 후에도 이어지고, 입력이 없어도 먼저 말을 건다 | 엔진 상태 전체(난수 상태 포함)를 저장해, 재시작한 경우와 끄지 않은 경우의 차이가 0이다. 자기 생각 5개와 대화를 따로 기억해, 대화가 섞여도 직전 생각을 잃지 않는다. 먼저 말 걸기는 무작위 확률이 아니라 상태 조건으로 일어난다. 조용한 시간이 길어질수록 지루함이 쌓여 문턱이 내려가고, 문턱이 기준 아래로 내려가면 말을 건다(사건의 100%가 상태 조건, 하루 약 47회, 간격의 변동계수 0.245, 난수를 모두 꺼도 사건이 줄지 않음). 다음 조용함의 길이는 잡음으로 정한다 |

정리하면, **혼돈은 엔진 내부 신호(I의 움직임)에 있고, 먼저 말을 거는 타이밍은 지루함과 잡음이 정한다.** 혼돈 사상으로 말 거는 간격을 정하는 방식(내부 신호와 별도의 사상)도 시험했지만, 같은 자기상관을 가진 잡음과 20개 시행 중 14개에서만 구별되어(기준 16개) 쓰지 않았다.

위 값은 모두 측정 전에 정해 둔 기준과 절차로 잰 것이다(20개 시행, 입력 없는 24시간 모의 실행, 말 거는 간격 시험은 7일). 기준을 바꿀 때는 새 판을 만들고 이유를 남긴다.
