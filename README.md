# INN — Intrinsic Neural Networks

**외부 입력 없이도 스스로 상태를 유지하고 행동하는 에이전트, "공학적 자아"를 만들어 보는 개인 연구 프로젝트**

> 상태: 진행 중 (v0.3.0, 2026-02). 소스코드는 비공개 저장소에서 관리하며, 현재 코드 정리와 검증을 진행하고 있다.
> 이 저장소는 프로젝트 소개용이다.

- 프로그램 저작권 등록: 한국저작권위원회 제 C-2026-011934 호
- 개발: 한정우 (개인 브랜드 란더, Landauer)

## 목표

"자아"라는 말을 그대로 쓰면 검증할 수 없기 때문에, 이 프로젝트는 자아를 **측정할 수 있는 성질**로 나누어 하나씩 구현하고
검증하는 것을 목표로 한다.

| 성질 | 공학적 정의 (검증 방향) |
|---|---|
| 능동성 | 외부 입력 없이도 스스로 행동을 시작한다 |
| 항상성 | 내부 변수를 기준 범위로 유지하려는 조절이 행동에 영향을 준다 |
| 연속성 | 재시작 후에도 이전 기억에 근거해 일관되게 행동한다 |
| 자기 모델 | 자기 내부 상태의 다음 변화를 스스로 예측한다 (향후 과제) |

"의식"이나 "주관성"을 주장하지 않는다. 위 성질들을 실제로 구현하고, 사전에 정한 기준으로 시험하는 것이 목표다.

## 현재 구성 요소 (v0.3.0, 2026-11 코드 분석 기준)

| 구성 요소 | 의도 | 지금 코드의 실제 상태 |
|---|---|---|
| 내부 신호 | 로지스틱 사상(r = 3.75)의 혼돈 영역으로 입력 없이도 변하는 신호 | 사상을 반복하지 않고 한 번만 계산한다. 시작값을 아주 조금 바꿔도 결과가 같아, 지금은 혼돈 신호가 아니다 |
| 스파이킹 신경망 (LIF 뉴런) | 입력을 시간에 따른 스파이크로 처리 | 모듈은 있으나 실제 동작 경로에 연결되어 있지 않다 |
| 부하 기반 자기 조절 | 내부 부하가 기준을 넘으면 처리를 줄이는 상태로 전환 | 시뮬레이터에는 회복이 있고, 대화 데모에는 회복이 없어 한 번 지치면 돌아오지 않는다 |
| 지속 기억과 능동적 생각 루프 | 재시작 후에도 이어지고, 입력이 없어도 먼저 말을 건다 | 마지막 상태 복원은 동작한다. 먼저 말 걸기는 지금 무작위 확률로 결정된다 |

위 차이를 출발점으로, 성질별 측정 기준을 먼저 정한 뒤 하나씩 구현한다.
