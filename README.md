# INN — Intrinsic Neural Networks

**외부 입력 없이도 스스로 상태를 유지하고 행동하는 에이전트, "공학적 자아"를 만들어 보는 개인 연구 프로젝트**

> 상태: 진행 중 (v0.3.0, 2026-02). 소스코드는 비공개 저장소에서 관리하며, 현재 코드 정리와 검증을 진행하고 있다.
> 이 저장소는 프로젝트 소개용이다.

- 프로그램 저작권 등록: 한국저작권위원회 제 C-2026-011934 호
- 개발: 한정우 (개인 브랜드 란더, Landauer)

## 목표

"자아"라는 말을 그대로 쓰면 검증할 수 없기 때문에, 이 프로젝트는 자아를 **측정할 수 있는 성질**로 나누어 하나씩 구현하고
검증하는 것을 목표로 한다.

| 성질 | 공학적 정의 (검증 방향) |
|---|---|
| 능동성 | 외부 입력 없이도 스스로 행동을 시작한다 |
| 항상성 | 내부 변수를 기준 범위로 유지하려는 조절이 행동에 영향을 준다 |
| 연속성 | 재시작 후에도 이전 기억에 근거해 일관되게 행동한다 |
| 자기 모델 | 자기 내부 상태의 다음 변화를 스스로 예측한다 (향후 과제) |

"의식"이나 "주관성"을 주장하지 않는다. 위 성질들을 실제로 구현하고, 사전에 정한 기준으로 시험하는 것이 목표다.

## 현재 구성 요소 (v0.3.0, 검증 전)

- **로지스틱 사상 기반 내부 신호**: x(n+1) = r·x(n)·(1 − x(n)), r = 3.75 의 혼돈 영역에서 외부 입력이 없을 때도 변하는 내부 신호를 만든다.
  결정론적 계산이므로 일종의 의사 난수 생성 방식이며, 일반 난수와 비교해 행동에 어떤 차이를 만드는지는 시험할 예정이다.
- **스파이킹 신경망 (LIF 뉴런)**: 입력을 시간에 따른 스파이크로 바꿔 처리한다.
- **부하 기반 자기 조절**: 내부 부하 지표가 기준을 넘으면 처리를 줄이는 상태("명상 상태")로 전환한다.
- **지속 기억과 능동적 생각 루프**: 대화와 상태를 저장하고, 입력이 없을 때도 내부 루프가 동작한다.

## 앞으로 할 것

1. 코드가 실제로 무엇을 하는지 정리하고 이 문서를 그에 맞게 갱신
2. 위 성질별로 측정 기준을 정하고 시험 (예: 강제로 부하를 높였을 때 기준 범위로 돌아오는 시간)
3. 입력 없이 도는 내부 루프의 자원 사용량 측정 (입력이 없을 때 쉬는 구조보다 자원을 더 쓰는지)
4. 로지스틱 사상 신호와 일반 난수의 비교
